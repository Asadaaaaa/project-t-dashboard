# ProjectT Dashboard

Modern, responsive web dashboard for ProjectT built with React 18, TypeScript, Vite, and Tailwind CSS.

## 🚀 Features

- **RBAC Authentication**: Role-based access control with secure JWT tokens.
- **WhatsApp Hub**: Real-time WhatsApp pairing QR code and connection status indicator.
- **Daily AI Summary**: View, filter by date, and one-click copy structured Markdown reports generated by Gemini AI.
- **Action Items & To-Do Tracker**: Track pending and completed tasks extracted from chat discussions.
- **Administration**: Manage users, custom roles, and granular permissions.

## 📦 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
npm install
```

### Environment Configuration
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Configure `VITE_API_URL` to point to your ProjectT Controller API.

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
